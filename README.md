# 🎉 Event Hub – Landing Page

A modern, responsive and visually attractive landing page for an event planning and venue booking brand, built using HTML5 and CSS3.

## 🌟 Project Overview

Event Hub is a static landing page designed to showcase event planning services and venues. It provides visitors with an attractive interface to explore different events, learn about services and contact the brand.

The project focuses on clean UI design, responsive layouts and a consistent colour theme.

## ✨ Features

- 📌 Sticky Navigation Bar
- 🎯 Attractive Hero Section with Call-to-Action Button
- 👥 About Us Section
- 💎 Features and Services Section
- 💍 Wedding Events Section
- 🎂 Birthday Party Section
- 🏢 Corporate Events Section
- 📞 Contact Section
- 🔗 Social Media Links
- 📱 Responsive Design for Mobile and Desktop
- 🎨 Modern Dark Navy and Golden Colour Theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/prathmeshp290605-png/Event-Hub-Landing-Page.git
```

2. Open the project folder:

```bash
cd Event-Hub-Landing-Page
```

3. Open the folder in Visual Studio Code:

```bash
code .
```

4. Open `index.html` using the Live Server extension.

5. View the website in your browser.

## 🎨 Design Theme

- Primary Colour: Dark Navy
- Accent Colour: Golden
- Background: Light Cream
- Typography: Poppins

## 📱 Responsive Design

The landing page uses CSS Flexbox, CSS Grid and media queries to provide a user-friendly experience across desktop, tablet and mobile devices.

## 🎯 Project Objective

The objective of this project is to develop a visually appealing static landing page while practicing fundamental HTML5 and CSS3 concepts, including page structure, styling, navigation, layout design and responsive web development.
